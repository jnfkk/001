# 美发智能体 · Salon Studio

一个面向美发门店的开发原型：顾客拍照或上传照片，浏览 6 款发型建议，并与理发师对照剪裁、烫发、染发的方案参考。顾客页和理发师工作台属于同一个原型，不是具有独立账号权限的生产后台。

## 直接打开体验版

运行 `npm run export:offline` 生成 `artifacts/hair-lab-demo.html`。将这个单文件下载到电脑，用 Chrome 或 Edge 打开即可体验，无需安装 Node、启动服务、联网或提供密钥。发型参考图、样式和交互代码均已内嵌。支持上传照片、发型筛选与对比、理发师方案和沟通单下载；相机能否使用取决于本机浏览器及授权。离线版本始终为示例参考模式，不调用真实图像 API，也不将照片发往服务器。

当前聊天环境没有公开端口预览；在云机启动服务并不会生成手机或电脑可访问的网站地址。云环境的“发布”保存环境配置和快照，不等同于将应用部署为公开网站。要提供真正的手机访问链接，需要另行部署 HTTPS 网站。

## 本地运行

使用 Node.js 24.5 或以上版本。应用运行不依赖第三方包；浏览器测试使用开发依赖 Playwright。

```sh
cd /workspace/001
npm start
```

默认监听 `0.0.0.0:3000`。需要调整时设置 `HOST` 或 `PORT`。在有图形浏览器的本机打开该服务即可使用；手机摄像头通常要求 HTTPS 或本机 `localhost`，普通局域网 HTTP 页面可能无法启用摄像头，可使用照片上传。

`npm start` 实际执行 `node --use-env-proxy server.mjs`，使用 Node 官方支持的环境代理能力读取 `HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY`。云环境提供代理和受信任 CA 时，应保留平台注入的代理与 `NODE_EXTRA_CA_CERTS` 设置；不关闭 TLS 证书验证。自行直接启动时也应使用相同的 `--use-env-proxy` 参数。接口域名 `api.openai.com` 仍须由环境网络策略允许，启动参数不会绕过域名限制。

```sh
npm test
```

测试覆盖接口状态、静态文件访问限制、照片格式验证，以及通过模拟服务验证图像编辑请求；测试不会访问收费图像接口。

浏览器回归测试：

```sh
npm ci --cache /tmp/salon-npm-cache --ignore-scripts
npm run test:ui
```

测试自动启动临时服务，覆盖桌面与手机布局、6 款参考、筛选与排序、三款对比、剪烫染工作台、沟通单下载、上传、模拟摄像头、镜头切换竞态、模拟六款生成及清除照片。优先使用系统 `/usr/bin/chromium`；其他机器可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`，或先运行 `npx playwright install chromium` 安装测试浏览器。截图写入被 Git 忽略的 `artifacts/`。所有图像 API 均为模拟，不产生生成费用。

## 演示与真实试发

未设置 `SALON_IMAGE_API_KEY` 时为演示模式。页面上的发型素材用于展示风格，不能称为顾客照片经过 AI 换发后的效果。`GET /api/status` 可确认当前模式；未配置图像服务时，`POST /api/try-on` 明确返回 `503 IMAGE_SERVICE_NOT_CONFIGURED`。

第一版图库使用 6 款女性发型的 AI 生成参考素材，不是用户照片。偏好排序按用户填写的长度与打理时间运行，不进行照片人脸分析；理发师方案来自 `public/styles-data.js` 中预设的咨询资料。真实试发接入后会单独标注个人生成图与剩余参考图。目前没有自动检测脸型、发质、底色或生成针对个人的精确染发配方。

真实试发接口已提供接入路径：在服务进程中安全设置 `SALON_IMAGE_API_KEY` 后重启服务。密钥应来自你有权使用、已开通图像编辑能力的 OpenAI API 账号；不要写入前端、Git 仓库或聊天记录。

后端固定调用 `https://api.openai.com/v1/images/edits`，使用 `gpt-image-1`、`1024x1536`、`medium`，每次请求生成一张图片。前端不能传入接口地址、模型或密钥。一个完整的 6 款真实试发通常需要 6 次生成，会产生模型费用，实际耗时和成功率取决于服务与图片内容。模型结果仍可能改变人物细节或与实操效果有差异，需人工检查；演示测试不等于已经验证了付费服务。

浏览器取消试发、删除照片或关闭页面导致请求断开时，后端会将取消信号传给上游图像请求；每次生成也有 150 秒超时。取消会尽力停止继续传输和等待，但服务商已经开始处理的任务仍可能产生费用，不能保证退款或完全停止远端计算。

接口接受 PNG、JPEG、WebP 的 base64 data URL，单张图片不超过 10 MB，请求体不超过 15 MB。照片在此服务中只用于当前请求，不保存到磁盘；真实试发会把照片和发型描述传给图像服务商，使用前应取得顾客同意，并确认服务商的数据处理条款。浏览器内是否保留选择结果以页面行为为准，离店前应清除顾客照片。

## 理发师参考的适用范围

发型建议、剪裁步骤和烫染方向属于辅助沟通资料，不是对顾客发质、头皮状况或染后结果的诊断。实际方案需要现场确认发长、发量、受损情况、漂染历史、当前底色及顾客习惯。药剂配比、温度、作用时间与补色方式，应由专业理发师依据所用品牌说明、发束测试和必要的过敏测试确定。

## 部署与继续开发

已有 GitHub 仓库时，可先按 [GitHub Pages 参考体验页说明](deploy/GITHUB-PAGES.zh-CN.md) 发布静态体验页。`npm run export:pages` 生成 `docs/index.html`，不携带后端密钥或个人照片；是否可部署仍需核实仓库权限、Pages 支持和实际构建结果。

手机在线体验的推荐路径与具体配置见 [Render 部署说明](deploy/RENDER.zh-CN.md)。项目已提供 Dockerfile；账号连接、代码推送、实际部署和公网验收仍需完成。云环境本身的发布不等于网站上线。

此版本没有登录鉴权、顾客/理发师权限隔离、生产级限流或门店数据存储。**不要将带真实密钥的原始接口直接公开部署。** 上线前应补充身份认证、门店权限、费用额度与限流、隐私授权及删除机制，并通过 HTTPS 提供服务。后端不会把密钥发给浏览器，也不记录照片和提示词；这不等于已经完成生产安全审计。

云任务使用现有隔离的 `/workspace/001` checkout，直接在该目录继续开发；除非用户明确要求，不创建 Git worktree。依赖和源文件可以保留，服务进程需要每次启动；运行 `npm start` 后检查 `/api/status`，再检查顾客页能加载。`imageEditingConfigured: true` 仅表示有配置值，不证明密钥有效，付费调用需单独授权验证。
