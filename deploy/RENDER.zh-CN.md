# 手机访问的体验版部署

建议先用 Render Web Service 托管当前 Node 应用，使用平台分配的 HTTPS 地址。无需先购买域名或单独管理服务器。这里记录部署准备，不代表已经部署成功。

## 账号与代码准备

1. 由项目所有者注册 https://render.com/ ，连接自己的 GitHub 账号。
2. 代码需要先保存到可供 Render 访问的 GitHub 仓库。目前项目修改仍在云工作区；仅连接当前 `jnfkk/001` 远端的旧 README 不会部署出本应用。确认代码推送后再创建服务。
3. 在 Render 创建 Web Service，选择包含本项目的仓库及实际分支。服务根目录为仓库根目录，使用 Docker 环境，Dockerfile 为 `./Dockerfile`。
4. 按 Render 当时提供的方案选择规格并确认账单。这里没有固定付费方案或自动购买操作，也不承诺永久免费、具体额度或最新价格。

## 当前演示版设置

- 应用通过 `PORT` 环境变量监听端口，`HOST=0.0.0.0` 已在镜像内设置。
- 启动命令由 Dockerfile 提供，无需额外安装 Node 或填写 npm 构建命令。
- 健康检查路径使用 `/api/status`。
- **暂不配置 `SALON_IMAGE_API_KEY`**。状态应返回 `imageEditingConfigured: false`、`mode: demo`；上传客户照片只在浏览器会话中使用，不会调用付费图像服务。
- 应用不需要磁盘卷或数据库。当前照片与选择在刷新后清除，理发师工作台不具有独立账号权限。

Render 完成部署后会显示实际服务地址。只使用平台真正返回的地址，不根据服务名称猜测链接。用目标门店的手机访问，检查首页、照片上传、六款参考、对比、理发师方案、下载以及相机授权。免费或试用方案可能存在休眠与资源限制，应以平台当时说明和实际体验为准。

## 接入真实试发前

真实生成还需要门店身份认证、权限与调用额度。当前 API 每次编辑最多等待 150 秒，完整六款由浏览器逐次请求；需核实部署方案与图像服务的连接时限，正式版宜改为后台任务和进度查询，以适应手机切后台和网络中断。

当前后端固定接入 OpenAI 图像编辑服务。模型费用与托管费用分别结算。部署地区、服务支持范围、门店访问效果和客户照片处理要求均需实测确认；不能认为换到国内服务器就自动解决图像 API 可用性。

如果主要面向中国大陆门店长期使用，可在实测后选国内云节点，配置自有域名、HTTPS 及适用的备案流程，并选定在部署地区可用的图像服务。

## 本地验证容器

```sh
docker build -t hair-lab-demo .
docker run --rm -p 3000:3000 hair-lab-demo
```

然后内部检查 `/api/status` 和首页。Docker 构建只包含服务端、网页与发型素材；不会打包 `.env`、Git 元数据、测试截图或开发依赖。平台部署和公网验收仍须单独完成。
