# 现有 GitHub 仓库的参考体验页

`npm run export:pages` 将单文件参考体验页生成到 `docs/index.html`，同时生成 `.nojekyll`。网页内嵌脚本、样式与参考图片，不依赖项目站点根路径；可放在 GitHub Pages 的仓库子路径下。

网页明确标注“在线参考体验版”。支持拍照、上传、发型对比、理发师方案与沟通单下载。用户照片仅保留在本机浏览器会话中，不调用 `/api/status`、`/api/try-on` 或第三方图像服务。它不提供真实个人 AI 换发型，也不公开后端接口或密钥。

发布路径为仓库 `main` 分支的 `/docs`。启用前应通过 GitHub API 确认仓库可见性、Pages 可用性和账号权限。不要为了启用 Pages 自动修改仓库可见性、升级账户或购买方案。如平台要求额外付费，先让所有者确认。

代码推送、Pages 设置、构建完成和公开访问是四个不同步骤，分别确认。页面地址只使用 GitHub 实际返回的 `html_url`，不根据用户名猜测并声称已经上线。发布后用该实际 HTTPS 地址检查页面、资源、手机尺寸布局和拍照授权。

当前环境需要访问 `api.github.com` 才能查询部署设置；访问实际 Pages 域名才能完成公网验收。若联网策略阻拦，应保存相应域名要求，由所有者在环境设置应用后继续。普通 HTTPS Git 读取成功不代表 GitHub API、推送或 Pages 管理也有权限。
